Surrogate pair bugs in JavaScript: why emoji get split

JavaScript strings are UTF-16, so cutting one at the wrong index can leave half an emoji behind. That half is a lone surrogate, and it breaks JSON, URLs and rendering.

What a surrogate pair is, and what a lone surrogate is

A JavaScript string is a sequence of 16-bit code units. Characters in the Basic Multilingual Plane fit in one unit. Everything above U+FFFF, including most emoji, needs two: a high surrogate (0xD800 to 0xDBFF) followed by a low surrogate (0xDC00 to 0xDFFF). Together they form a surrogate pair.

A lone surrogate is one half of that pair with no partner. It is not a valid character. It renders as a replacement box, encodeURIComponent throws a URIError on it, TextEncoder silently replaces it with U+FFFD, and many JSON serializers and databases reject or corrupt it. The bug is hard to notice because the broken string only shows up when real text contains an emoji at exactly the wrong position.

The classic victims are helper functions that every project has: truncate with an ellipsis, take the first letter for an avatar, pad or wrap to a column width.

With input '\u{1F600}' and a limit of 1, truncate returns '\uD83D'. initials does the same for a name that starts with an emoji.

Real bugs fixed in the wild

This is not a beginner mistake. It was fixed in google/budoux#1411 and microsoft/vscode-js-debug#2423, both merged. Those projects are maintained by people who know Unicode well, and the bug still got in, because unit tests rarely put an emoji at the cut point. The lesson is that you cannot rely on remembering; you need inputs that deliberately land on the boundary.

FAQ

What is a lone surrogate?

Half of a UTF-16 surrogate pair without its partner. It is not a valid character, and it breaks encodeURIComponent, TextEncoder round trips and many serializers.

Is code point slicing enough?

It avoids lone surrogates, but grapheme clusters such as flags, skin tone sequences and family emoji can still be split into odd pieces. Use Intl.Segmenter when the user sees the result.

How do I check a string for lone surrogates?

On Node 20 and newer, call str.isWellFormed(). On older runtimes, use a regular expression that matches an unpaired high or low surrogate, as in the generated test above.

Does substr have the same problem as slice?

Yes. substr is deprecated and counts code units like slice and substring, so it can cut a pair in half too.

Do I need to write emoji test cases myself?

No. breakhound reads your TypeScript types and feeds emoji, flags and lone surrogates to every string parameter automatically. You only run npx breakhound ./my-lib.
